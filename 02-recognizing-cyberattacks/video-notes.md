# Recognizing Cyberattacks

## Overview

Explains how cybercriminals achieve financial gain and introduces cybersecurity terminology needed to recognize cyberattacks. It distinguishes incidents from breaches, covers core IT/security concepts, categorizes cyberattacks, describes common attack methods and malware types, and outlines protection, detection, and avoidance measures. 

## Key Concepts

- **Cybercrime motives:** stealing from bank accounts, selling stolen data, ransomware extortion, insider trading, crypto jacking.
- **Incident vs breach:** an **incident** compromises integrity, confidentiality, or availability; a **breach** is confirmed disclosure of data to an unauthorized party.
- **Core terminology:** IT, OT, IoT, DNS, IP addressing, middleware, API, Cloud Access Security Broker.
- **Cyberattack categories:** hacking, social attacks, physical attacks, environmental attacks, misuse, error.
- **Common attacks:** brute-force, phishing, smishing, vishing, consent phishing, spear phishing, whaling, HR phishing, Business Email Compromise/Email Account Compromise, spoofing.
- **Malware types:** ransomware, RaaS, scareware, spyware, Trojan Horse, adware, worm, virus.
- **Other attacks/vulnerabilities:** APT, credential stuffing, XSS, DoS/DDoS, DNS hijacking, drive-by attack, exploit, Golden Ticket Attack, insider threat, juice jacking, MITM, security misconfigurations, supply chain attack, web shell.
- **Physical threats:** dumpster diving, shoulder surfing, tailgating.
- **Protection measures:** antivirus/spam filters/firewalls, web filters, updates/patches, encryption and VPN, regular backups, complex passwords and password managers, MFA.
- **Spam detection:** avoid unknown senders, do not open attachments/links, do not send read receipts, filter and delete spam.
- **Phishing detection:** beware urgency, threats, fake links, spelling/grammar errors; verify via known websites, direct calls, or forwarding to the supposed sender.
- **Adware signs:** unexpected ads, homepage changes, redirects, slow/crashing browser, new toolbars/extensions/plugins, unwanted software installs.
- **Breach signs:** suspicious network activity, password/account changes, suspicious files, banking anomalies, loss of access, data leakage, slow connections, security warnings.
- **Website anomalies:** code inconsistencies, admin login problems, traffic changes, design/layout/content changes, performance/availability issues.

## Key Takaways
- Cyberattacks exploit technical vulnerabilities, human behavior, physical security weaknesses, and configuration errors to steal information, gain unauthorized access, or disrupt operations.
- Knowing and understanding the difference between security incidents and confirmed data breaches helps determine the appropriate response.
- Recognizing phishing, social engineering, malware, and suspicious system activity is essential for identifying potential cyber threats.
- Continuous monitoring, user awareness, and adaptive security practices are necessary to detect and respond to evolving cyber threats.

## Key Application
- Apply cybersecurity terminology to accurately document, classify, and communicate security incidents.
- Identify suspicious emails, links, attachments, impersonation attempts, and urgent requests before interacting with them.
- Monitor systems, networks, accounts, and websites for unusual activity, unauthorized changes, data leakage, and potential compromise.
- Verify unusual requests through trusted websites or independently confirmed contact details, especially before sharing sensitive information or authorizing financial transactions.
