# Data Security Tools and Protecting Against Cyber Threats

## Overview

The necessary steps to protect against cyber threats include Identification, Protection, Detection, Response, and Recovery. These steps focus on identifying vulnerabilities, implementing multi-layered defences, detecting threats, responding to security incidents, and restoring affected systems and operations with minimum disruption.

## Key Concepts

\- Identification: The first step in protecting against threats is to identify vulnerabilities in your environment. A cybersecurity risk assessment identifies where valuable data is kept, determines the risk of a cybersecurity incident, and helps manage vulnerabilities. Identifying vulnerabilities should be a continuous, ongoing process.

\- Protection: Multi-layered defences protect IT infrastructure, data, applications, devices, and network resources. These include application security, network security, endpoint security, cloud security, and Internet of Things (IoT) security.

\- C-I-A Triad: Data security is based on Confidentiality, Integrity, and Availability.

- Confidentiality: Only the people who should see data can see it.
- Integrity: Only the people who should be able to modify or delete data can do so.
- Availability: People can access their data when they need to.

\- Data Loss Prevention (DLP): Software that prevents potential data breaches by monitoring, detecting, and blocking sensitive data while in use, in motion, or at rest.

\- Server Security and Server Hardening: Server security protects data and resources held on physical servers. Server hardening means increasing server security beyond its default configuration. Cloud providers can configure and maintain servers, including patching, security hardening, logging, and auditing.

\- Firewalls: Hardware, software, and network firewalls filter or restrict network access and traffic. A Web Application Firewall (WAF) protects web applications by filtering and monitoring HTTP traffic between a web application and the Internet.

\- Antivirus: Security software that scans for, detects, blocks, and eliminates malware that reaches a computer or network.

\- Multi-Factor Authentication (MFA) and Two-Factor Authentication (2FA): Security tools that require users to provide multiple pieces of evidence before accessing services or an account, helping protect against password vulnerabilities.

\- Detection: Detection identifies threats that pass through defences. Continuous monitoring and breach detection tools help recognize active threats, alert security staff, contain breaches, and mitigate damage.

\- Reverse Proxy and Load Balancer: A reverse proxy acts as a gateway between users and an application origin server. A load balancer acts as a reverse proxy and distributes traffic across several servers.

\- Demilitarized Zone (DMZ): A physical or logical perimeter that adds an extra layer of security to an organization's internal local-area network from untrusted traffic.

\- Cloud Access Security Broker (CASB): Software that sits between cloud services and cloud users, monitoring activity and enforcing security policies.

\- Identity and Access Management (IAM): The practice of ensuring that only the correct individuals have access to an organization's resources, at the right times, for the right reasons.

\- Cloud Security Posture Management (CSPM) and Software as a Service Security Posture Management (SSPM): Practices that continuously benchmark and manage cloud or SaaS instances, identify misconfigurations and vulnerabilities, and prioritize and remediate cloud risks.

\- Application Programming Interface (API): A computing interface that defines and standardizes interactions between two pieces of software. APIs are an essential source of data for security operations.

\- Endpoint Detection and Response (EDR): Tools and solutions that detect, investigate, and mitigate suspicious activity that may not have a known behavioral pattern or malware signature.

\- Extended Detection and Response (XDR): Platforms that extend traditional endpoint detection and response to include a wider set of security telemetry and event data.

\- Open Extended Detection and Response (Open XDR): A vendor-neutral approach that collects security telemetry from existing security tools for alert correlation, noise reduction, and increased response speeds.

\- Network Operations Centre (NOC) and Security Operations Centre (SOC): A NOC ensures that corporate IT infrastructure sustains normal business operations, while a SOC focuses on protecting the network against cyber-attacks through cybersecurity personnel, threat detection, incident response processes, and supporting security technologies.

\- Vulnerability Assessment (VA) and Vulnerability Management (VM): VA identifies, classifies, and prioritizes vulnerabilities in business systems. VM solutions identify, track, and prioritize vulnerabilities to optimize prevention activities such as patching, upgrades, and configuration fixes.

\- Managed Risk (MR): A service that continuously scans networks, endpoints, and cloud environments for risky software, assets, misconfigurations, and accounts.

\- Managed Detection and Response (MDR): A component of SOC-as-a-service (SOCaaS) that provides continuous monitoring, threat detection, and incident response through a third-party vendor.

\- Security Information and Event Management (SIEM): An integrated tool that collects and aggregates security events and alerts from different security products to identify potential threats within an organization's environment.

\- Response: A Cybersecurity Incident Response Plan provides instructions for responding to a serious security incident, data breach, data leak, ransomware attack, or loss of sensitive information. Faster responses can help limit damage.

\- Recovery: The final step after an incident involves eradicating the threat, restoring affected systems and operations, and minimizing disruption. A recovery plan identifies tools and procedures to minimize downtime and bring critical systems back online.

\- Recovery Time Objective (RTO): The maximum length of time it should take to restore normal operations following an outage or data loss.

\- Recovery Point Objective (RPO): The maximum amount of data an organization can tolerate losing.

## Key Takeaways

1. Cybersecurity requires five main steps: Identification, Protection, Detection, Response, and Recovery.
2. Identifying vulnerabilities through cybersecurity risk assessments and vulnerability scans should be a continuous, ongoing process.
3. Multi-layered defences, data security, firewalls, antivirus, and multi-factor authentication help protect infrastructure, information, and accounts against cyber threats.
4. Continuous monitoring, breach detection tools, and security technologies help identify threats, alert security staff, and support incident response.
5. Incident response and recovery plans help limit damage, eradicate threats, restore affected systems, minimize downtime, and maintain business services with minimum disruption.

## Key Application

1. Conduct cybersecurity risk assessments and vulnerability scans to identify valuable data, determine cybersecurity risks, and prioritize vulnerability mitigation.
2. Implement multi-layered security controls, including application, network, endpoint, cloud, and IoT security, alongside firewalls, antivirus, MFA, and data loss prevention software.
3. Use continuous monitoring and relevant detection tools, such as EDR, XDR, SIEM, and intrusion detection tools, to identify suspicious activity and potential security breaches.
4. Develop a Cybersecurity Incident Response Plan that provides clear instructions for responding to security incidents, data breaches, ransomware attacks, and the loss of sensitive information.
5. Prepare a recovery plan that identifies critical services, establishes RTO and RPO objectives, and prioritizes the restoration of affected systems and operations with minimum disruption.
